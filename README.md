
# Coffee Archive ☕｜咖啡風味檔案館

**Every Cup Has a Story.**

一杯咖啡，不只有酸與苦，還有產地、風土、處理方式，以及藏在風味背後的故事。

Coffee Archive 是一個以咖啡知識整理與探索為核心的互動式網站，希望讓咖啡不再只是飲品，而是能夠被閱讀、理解與收藏的風味記憶。

## 專案理念

本專案以星巴克咖啡豆為主要研究對象，整理常態咖啡豆、季節限定咖啡豆與典藏系列，透過數位圖鑑呈現咖啡豆的基本資訊與故事。

除了查詢咖啡豆，也希望讓使用者進一步理解咖啡從產地到杯中的過程。

## 網站功能

### 01｜咖啡風味圖鑑 Coffee Collection

- 收錄常態豆、季節豆與典藏豆
- 展示咖啡豆產區、處理法、烘焙程度與風味
- 提供咖啡故事與詳細介紹
- 支援咖啡名稱、產地及風味關鍵字搜尋
- 依照咖啡類別、烘焙程度與處理法篩選

### 02｜咖啡處理法百科 Processing Guide

介紹常見的咖啡處理方式：

- 水洗處理 Washed
- 日曬處理 Natural
- 蜜處理 Honey
- 半水洗處理 Semi-Washed
- 濕刨處理 Wet-Hulled
- 厭氧發酵 Anaerobic Fermentation

### 03｜沖煮指南 Brewing Guide

提供基礎沖煮知識與建議，協助使用者理解咖啡粉水比例、研磨程度、水溫及沖煮方式對風味的影響。

## AI 協作與 Agentic Workflow

本專案透過 `AGENTS.md` 建立 AI 協作規範，讓 AI 在後續修改與擴充網站時遵循一致的工作原則。

主要規範包括：

1. 修改前閱讀既有專案結構與資料格式。
2. 新增咖啡豆時檢查重複資料。
3. 不自行編造咖啡豆的官方資訊。
4. 保留原有網站設計與既有功能。
5. 修改後檢查資料格式、互動功能及頁面顯示。
6. 將無法確認的資訊標示為待補。

## 資料來源與使用說明

咖啡豆資料以星巴克公開產品資訊及蒐集的咖啡知識資料為基礎進行整理。部分季節與典藏豆資料仍需進一步交叉查證。

網站中的咖啡故事為整理後的介紹文字，並非星巴克官方原文。

本網站為非商業性學習專案，並非星巴克官方網站，也不代表星巴克的立場或認可。
